# ==============================================================================
# requirements-dev.txt — tools needed ONLY for development and testing.
#
# WHY SEPARATE FROM requirements.txt?
#   Your production Docker image should not ship pytest, coverage tools, etc.
#   Smaller image = smaller attack surface + faster deploys. So dev tools live
#   here and are installed with:  pip install -r requirements-dev.txt
#   (This file installs the runtime deps too via the "-r" include below.)
# ==============================================================================

# Include everything from the runtime requirements so a dev has the full set.
-r requirements.txt
